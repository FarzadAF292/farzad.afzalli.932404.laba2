## Описание

В данной лабораторной работе была доработана страница из лабораторной работы №1 с использованием CSS.

В работе реализованы:

- внешний CSS-файл;
- inline-стили;
- внутренний блок `<style>`;
- CSS-переменные;
- позиционирование `static`, `relative`, `absolute`;
- состояния `:hover`, `:active`, `:focus`, `:visited`;
- анимированная градиентная кнопка;
- оранжево-белая цветовая схема.

## Используемые технологии

- HTML5
- CSS3
